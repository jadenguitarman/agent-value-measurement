# Agent Value Measurement

Self-contained measurement demonstration for the AI agent value article.

The demo will analyze synthetic control and agent-variant exposures, business outcomes, interaction costs, uncertainty, and segment-level regressions.

## Scope

- Deterministic synthetic event fixtures
- Outcome, cost, latency, and net-value summaries
- Uncertainty estimates and segment comparisons
- Explicit labeling that results are synthetic and not causal evidence about a live system
